# KrishiMitra Scheme Dataset v1

**45 curated records:** 30 central + 15 Maharashtra-focused.

This is for the hackathon MVP. It is a retrieval catalog, not a legal eligibility engine.

Kiro must never invent subsidy amounts, deadlines, eligibility rules, required documents, or application status. Those must be checked against the linked official source.

The dataset is intentionally separate from training data.
